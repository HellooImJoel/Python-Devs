Trataremos de resolver un problema utilizando una red neuronal.
En este caso se trata de un problema de clasificacion binaria donde se tiene dos circulos concentricos
de puntos, el cual se quiere separar en dos clases diferentes. 
Este problema simula un enfrentamiento que surgen en Game of Thrones donde uno de los ejercitos se encuentra 
totalmente rodeado por las fuerzas enemigas.
